# Radio Console — brand guide

**Proposed display name:** Radio Console
**Tagline:** *The console's second act.*

## Why this name

This is the generation the RTest work grew from; it keeps the working title and the linear dial that generation used. Lineage: PiRadio → RadioXX → Radio Console v1 → this repo → RTest (Anderson Console).

## The mark

The slide-rule dial: a cream band of tick marks, a red needle, a warm pilot lamp, two knobs.
